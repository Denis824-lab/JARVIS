## Короткое описание GitHub

Персональный голосовой помощник с общей памятью, управлением Windows и Linux и вниманием к важным событиям. Один JARVIS — все твои устройства.

## Подпись

Один помощник. Все твои устройства.

## Краткое представление

JARVIS — проект личного помощника, который объединяет голос, память и действия в одной системе. Он задуман, чтобы помогать с повседневными делами, работать с компьютерами и подключёнными сервисами и вовремя сообщать о важном.

Приятный голос, выразительные анимации и спокойный технологичный интерфейс делают общение естественным. Прозрачные действия, управляемые права и контроль расходов сохраняют систему понятной её владельцу.

## Зачем существует проект

У цифровой жизни много отдельных окон: письма, задачи, файлы, проекты и сообщения. JARVIS создаётся, чтобы обращаться ко всему этому обычными словами и меньше держать в голове.

Это личный проект с долгим горизонтом. Его основа — переносимые данные, заменяемые модели и небольшие понятные модули, которые можно развивать годами.

## Текущий статус

Проект находится на этапе проектирования. Требования и архитектурные решения документируются; интерфейс, голос и первая рабочая версия готовятся к разработке.
