# Текущий статус

Обновлено 2026-10-03 после первой бесплатной голосовой пробы. Основное приложение ещё не реализуется.

## Подтверждено

- Образ JARVIS Тони Старка: спокойная манера, контекст, компетентность, инициативность и лёгкая ирония; создан BEHAVIOR.md.

- Постоянное облачное ядро, независимое от выключения домашних устройств.
- Голос + управление компьютером + простая память как направление первого выпуска. Первый ноутбук Windows 11 — предложение для приёмки.
- Универсальная основа; Яндекс Игры не ограничивает продукт. Требуемые направления: Gmail, Яндекс Почта, личный Telegram, веб и разные задачи ПК.
- PlusVibe `.ru`, дешёвые явные маршруты, автоматический резерв без лишнего шума, с контролем цены.
- ПК: Windows 11, i5-11400F, RX 580, 16 GB RAM 3200. Ноутбук: Ryzen 7 5825U, 16 GB, Windows 11/Zorin OS dual boot на разных SSD.
- Особый приоритет дизайна/анимаций; Genesis — референс приемлемого уровня. Владелец может создавать motion в After Effects.
- Для голоса сначала бесплатные варианты; платный TTS не основа. Все четыре Piper/Silero-образца отвергнуты после прослушивания: роботизированное и пугающее звучание. Нужна естественная человеческая речь; желательный референс — русский дубляж JARVIS, точная копия не обязательна. Qwen3-TTS и Chatterbox Multilingual исследованы как следующие кандидаты, местные пробы ещё не выполнены.
- AI примерно 200–300 ₽, инфраструктура желательно бесплатно; сервер при необходимости до 400 ₽ отдельно.

## Выполнено

Прочитан и сохранён исходный концепт. Созданы/обновлены правила агентов, README и проектная документация. Прайс Excel прочитан без изменений; проверены кандидаты маршрутов и публичные документы PlusVibe. Публичный каталог прочитан без ключа, но inference не проверялся. Изучены официальные способы Gmail/Яндекс/Telegram. Подготовлены визуальный процесс, motion-бриф и тексты репозитория.

Реальные аккаунты не подключались; платных запросов/развёртывания не было. Выбор голосов, финального макета и стека открыт. Исследование документации не равно рабочей интеграции.
