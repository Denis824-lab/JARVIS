# JARVIS

**Один помощник. Все твои устройства.**

JARVIS — проект личного голосового помощника для повседневной цифровой жизни. Он задуман как система, которой можно поручить действие, доверить мысль и задать вопрос о своих делах — обычными словами.

В центре проекта — приятный голос, общая память, управление компьютерами и внимание к тому, что легко упустить. Всё это объединяет спокойный технологичный интерфейс, где каждое действие понятно, а каждое движение имеет смысл.

Образ взаимодействия вдохновлён JARVIS Тони Старка: спокойный, компетентный помощник, понимающий контекст и уместно проявляющий инициативу. [Характер и поведение](docs/BEHAVIOR.md) зафиксированы отдельно, чтобы сохранять их при развитии системы.

**Статус: проектирование. Рабочего приложения пока нет.** Документы обновлены 3 октября 2026 года. Облачное ядро и первый сценарий подтверждены; технологии, голос и визуальный макет пока выбираются.

## Что мы создаём

JARVIS принимает просьбу обычным языком, получает нужный контекст, выбирает разрешённые инструменты, выполняет действие и сообщает проверенный результат. Можно спросить о доходе игры, попросить открыть программу, сохранить мысль или узнать об ответе на своё письмо.

Один помощник работает на нескольких устройствах. Простые локальные действия обходятся без платного AI. Облако помогает синхронизировать данные и доставлять напоминания, когда домашние устройства выключены. Владелец видит права, память, расходы и историю действий.

## Структура проекта

```text
JARVIS/
  AGENTS.md           Правила разработки для AI-агентов
  README.md           Точка входа
  DESIGN.md           Точка входа для визуальной работы
  concept.md          Исходный концепт
  docs/               Требования, план, объяснения и статус
    decisions/        Архитектурные решения и причины
  apps/               Будущие приложение, исполнитель и облачное API
  packages/           Будущие общие контракты и модули
  tests/              Будущие интеграционные и системные проверки
  assets/             Будущие проверенные визуальные и звуковые ресурсы
  prototypes/         Изолированные пробы до выбора технологий
  infra/              Будущие настройки развёртывания и миграции
```

Директории приложения подготовлены для будущей реализации. В `prototypes/voice/` находится отдельная бесплатная голосовая проба; её локальные результаты и модели исключены из Git. Это один репозиторий. Подробную разбивку пакетов создаём по мере появления реального кода.

## Запуск и данные

Команды сборки и запуска приложения появятся вместе с первым работающим этапом. Для отдельного сравнения голосов есть [инструкция пробы](prototypes/voice/README.md). Для прослушивания готовых WAV ничего устанавливать не нужно. Сервер и API-ключ для этой пробы не требуются. Ключи и личные данные не должны попадать в репозиторий.

## Рамки расходов

Цель AI: 200 ₽/месяц, верхний ориентир 300 ₽. Инфраструктура: желательно 0 ₽; сервер рассматривается отдельно в пределах 400 ₽/месяц, если бесплатный вариант не подходит. Это два отдельных бюджета. Изучены прайс и публичные документы PlusVibe; платные вызовы и проверка качества моделей ещё не выполнялись.

Облачное ядро продолжает работу при выключенных домашних устройствах. Микрофон, overlay и действия на конкретном компьютере требуют включённого исполнителя. Первым устройством приёмки предлагается рабочий ноутбук с Windows 11.
