# Первая голосовая проба

Отдельная локальная проба, не код основного приложения. Четыре мужских голоса на семи одинаковых русских фразах, с одинаковыми паузами и приблизительно выровненным уровнем. Никаких платных API и доступа к микрофону/аккаунтам.

Сначала слушать файлы A–D в `assets/voice-samples/`, затем смотреть ключ в `report.json`. Названия намеренно не произносятся в аудио. Выбор приятности делает владелец, результаты генерации сами по себе его не определяют.

## Воспроизведение пробы

Windows x64, Python 3.12, отдельная `.venv` в корне проекта. Зависимости только Piper — `requirements.txt`; полный проверенный набор с CPU PyTorch — `requirements-lock.windows.txt`. Этот файл фиксирует Windows-колесо PyTorch с хэшем; для Linux требуется собственное окружение и проверка. Модели скачиваются только с явно указанных официальных источников и кэшируются в игнорируемой папке `models/voice-probe/`.

Из корня проекта:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r prototypes/voice/requirements-lock.windows.txt
.venv/Scripts/python.exe -X utf8 prototypes/voice/prepare_samples.py --engine piper
.venv/Scripts/python.exe -X utf8 prototypes/voice/prepare_samples.py --engine silero
```

Первый запуск скачивает модели. Последующие используют кэш. Источники/лицензии моделей сохранены рядом с кэшем, хэши отражены в отчёте. SHA256 здесь фиксирует использованную версию, а не заменяет независимое подтверждение доверия к источнику. Голоса не включаются в распространяемую сборку автоматически.

## Что проверяет проба

Генерацию всех фраз, корректный непустой WAV, конечные значения аудио, пиковый уровень, длительность и затраченное время. Piper дополнительно измеряет первую порцию аудио; Silero использует генерацию фразы целиком. RSS после синтеза не является peak-памятью отдельно взятого движка. Время каждой фразы записано отдельно; последовательные голоса не дают сравнения одинаковых холодных запусков. Итоги — [VOICE_AUDITION.md](../../docs/VOICE_AUDITION.md).

Пока не проверяются: непрерывный диалог, работа под игровой нагрузкой, 20 повторов, отмена, Linux и захват микрофона. Эти проверки выполняются после выбора кандидата. Протокол полной проверки — [VOICE.md](../../docs/VOICE.md).
