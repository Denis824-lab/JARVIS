# JARVIS

**Один помощник. Все твои устройства.**

JARVIS — концепция личного голосового помощника для повседневных цифровых задач: поручить действие, сохранить мысль, задать вопрос о своих делах обычными словами. Ориентир — спокойный и компетентный помощник, который понимает контекст и уместно проявляет инициативу.

**Статус: проектирование. Рабочего приложения пока нет.** В репозитории только документация и одна изолированная голосовая проба. Облачное ядро и первый сценарий выбраны, технологии, голос и визуальный макет ещё обсуждаются.

## Что задумано

JARVIS принимает просьбу обычным языком, получает нужный контекст, выбирает разрешённые инструменты, выполняет действие и сообщает проверенный результат. Один помощник работает на нескольких устройствах: простые локальные действия обходятся без платного AI, облако синхронизирует данные и доставляет напоминания. Владелец видит права, память, расходы и историю действий.

## Что уже есть

- `docs/` — требования, архитектура, безопасность, бюджет, план этапов и журнал решений.

## Голосовая проба

Проба запускается отдельно от приложения: Windows x64, Python 3.12, виртуальное окружение в корне проекта.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r prototypes/voice/requirements-lock.windows.txt
.venv/Scripts/python.exe -X utf8 prototypes/voice/prepare_samples.py --engine piper
```

Подробности, ограничения и порядок прослушивания — в [README пробы](prototypes/voice/README.md). Модели и локальные результаты исключены из Git, ключи и личные данные в репозиторий не попадают.

## Структура

```text
JARVIS/
  AGENTS.md           правила разработки для AI-агентов
  README.md           точка входа
  DESIGN.md           точка входа для визуальной работы
  concept.md          исходный концепт

    decisions/        архитектурные решения и причины
  prototypes/         изолированные пробы
    voice/            проба голосов Piper и Silero
```

Каталоги приложения (`apps/`, `packages/`, `tests/`, `assets/`, `infra/`) появятся вместе с первым рабочим этапом. Сейчас их в репозитории нет, и структура выше описывает только существующие файлы.

## Ограничения

- Рабочего приложения нет: запускать нечего, кроме голосовой пробы.
- Нет API-слоя, облачной инфраструктуры и интеграций — только проектные документы.
- Нет автотестов: проба проверяет генерацию WAV, но не диалог и не работу под нагрузкой.
- Голос, стек и визуальный макет ещё не выбраны.
- Бюджет — ориентир, а не факт: платные вызовы моделей не выполнялись.

## Рамки расходов

Цель по AI — 200 ₽/месяц, верхний ориентир 300 ₽. Инфраструктура — по возможности 0 ₽; сервер рассматривается отдельно в пределах 400 ₽/месяц. Это два отдельных бюджета.
