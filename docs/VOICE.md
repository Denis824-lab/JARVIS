# Бесплатный голос: приоритет и сравнение

Обновлено 2026-10-03 после прослушивания владельцем. Все четыре образца A–D отвергнуты: звучат роботизированно, общение неприятно и даже пугает. WAV перемещены в корзину по просьбе владельца; [отчёт первой пробы](VOICE_AUDITION.md) сохранён. Быстрый синтез не компенсирует недостаточную естественность. Платный TTS пока не становится обязательным расходом.

## Новое направление после обратной связи

### Конкретный референс владельца: Fish Audio «Джарвис 2.0»

Владелец указал [этот голос](https://fish.audio/ru/m/0c7fd46820854a9e8c4010d911687b7a/) как нужное звучание. Идентификатор: `0c7fd46820854a9e8c4010d911687b7a`. Это подтверждённый референс по оценке владельца; агент прочитал страницу, но сам аудио не прослушал. На странице автор — Никита Дюк; описание связывает голос с «Железным человеком», но не подтверждает личность актёра или происхождение записей.

Теперь первая следующая проба — именно этот голос через Fish API, если доступен аккаунту. [API TTS](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) принимает `reference_id`, поэтому скачивание образца не обязательно для прямого подключения. Доступность выбранного ID, звук и задержку через API ещё проверить.

На 2026-10-03 [API-прайс](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits) указывает `s2.1-pro-free` за $0 и платный `s2.1-pro` за $15/1M UTF-8 bytes. По [объявлению провайдера](https://fish.audio/blog/s2-1-pro-free-api/) бесплатное окно действует до 2026-11-30, с Fair Use, без гарантии задержки/доступности; запросы могут сохраняться для улучшения модели. Не считать это бесплатным пожизненным сервисом. Для пробы использовать только синтетические тексты.

API-ключ необходим, в чат его не запрашивать. Перед бесплатной пробой явно закрепить `s2.1-pro-free`: API по умолчанию и при неизвестном имени модели использует платный `s2.1-pro`. Не переключаться на него автоматически. Ключа в проекте нет, запросы не выполнялись. Тариф сайта и API — разные условия; квоту сайта не переносить на API.

Прямая интеграция Fish не экспортирует библиотечный голос в локальные Qwen/Chatterbox. Перенос тембра в другой движок — отдельная проба с аудиореференсом и без гарантии одинакового звучания. Бесплатные локальные кандидаты остаются альтернативой на будущее.

Приёмка начинается с человеческого звучания: естественная разговорная интонация, плавная речь, убедительные паузы и спокойный мужской тембр. Голос русского дубляжа JARVIS из «Железного человека» — желательный звуковой референс; точная копия не обязательна. Чистый звуковой пример поможет уточнить конкретный дубляж и манеру. Не утверждать, что похожий тембр автоматически даёт естественную речь.

Следующие кандидаты по официальной документации, ещё без местных аудиопроб:

- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS): русский; VoiceDesign 1.7B создаёт голос по описанию, Base 0.6B/1.7B переносит характеристики аудиореференса. Предпочтительная следующая проба — создание собственного спокойного разговорного голоса, затем сравнение с референсом. Apache-2.0 в официальном репозитории.
- [Chatterbox Multilingual](https://github.com/resemble-ai/chatterbox): русский и voice cloning, версия V3 указана как текущая многоязычная модель. Второй кандидат для сравнения. Nano/Turbo в таблице разработчика англоязычные — не переносить их CPU-показатели на русский Multilingual.

Это исследованные кандидаты, не доказанные победители. Скорость и память на устройствах владельца пока не измерены. Не обещать мгновенный CPU-синтез, бесплатный постоянный GPU-хостинг или работу CUDA на RX 580. Сначала оценить короткую пробу по звуку, затем проверить задержку и подобрать исполнение в пределах бюджета. Не скачивать несколько больших моделей сразу только ради количества голосов.

Piper denis/dmitri и Silero aidar/eugene исключены из продуктового выбора. Не возвращать их автоматически как резерв и не предлагать новые лёгкие голоса без оснований ожидать улучшения естественности. Ниже сохранена история первой пробы.

## Архитектура

Облачное ядро хранит память, задачи и настройки, обрабатывает подключённые события. Исполнитель на активном устройстве может бесплатно синтезировать полученный текст. Выключение устройства прекращает только его воспроизведение и локальные действия, но не облачные функции. Уведомление в этот момент идёт на подключённый телефонный канал; голос на телефоне — отдельная проверка клиента.

Без оплаты за символы ≠ без ресурсов: синтез требует CPU/RAM и электричества. Бесплатный тяжёлый движок в облаке потребует вычислительной инфраструктуры, поэтому не обещаем его работу в бесплатном Workers.

## Первые кандидаты

После подтверждения образа стартовое направление прослушивания — спокойный мужской тембр, ясная дикция и естественные паузы. Начать с мужских вариантов Piper и Silero; сохранить смену голоса в настройках. Подробности характера — [BEHAVIOR.md](BEHAVIOR.md). Это не выбор победителя по описанию и не требование имитировать актёра.

| Кандидат | Что проверять | Роль-кандидат |
|---|---|---|
| Piper, русские `denis`, `dmitri`, `irina`, `ruslan` | Тембр, ударения, время первого аудио, паузы, лицензия каждой voice card | Лёгкая базовая реализация и профиль игрового ПК |
| Silero V5 Russian, доступные `aidar`, `baya`, `kseniya`, `xenia`, `eugene` | Русский текст/ударения, естественность, CPU/RAM PyTorch, условия конкретной модели | Альтернатива для слепого сравнения качества |
| RHVoice | Разборчивость, естественность и SAPI/Speech Dispatcher | Дополнительный лёгкий резерв, если потребуется |

Piper: [движок](https://github.com/OHF-Voice/piper1-gpl), [русские модели](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU), [правила voice cards](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md). Текущий движок GPL; лицензии голосов проверяются отдельно.

Silero: [официальный репозиторий](https://github.com/snakers4/silero-models). README перечисляет V5 Russian с автоударениями/омографами и CPU-примеры. Основные модели имеют отдельные noncommercial-условия; некоторые CIS base опубликованы под MIT. Не переносить MIT одного набора на все русские голоса; фиксировать применимую лицензию конкретного файла и предполагаемое использование до включения в распространяемую сборку.

RHVoice: [официальный репозиторий](https://github.com/RHVoice/RHVoice), поддержка русского/Windows/Linux. Его наличие не означает, что он удовлетворяет требованию «очень приятный»: это решает прослушивание.

Исторический выбор для первой пробы: Piper и Silero. После прослушивания четыре проверенных голоса исключены; скорость не означает пригодность. Голос и вычислительный путь остаются открытыми.

## Протокол прослушивания и измерений

Начать с четырёх фиксированных голосов: два Piper и два Silero. Можно выбрать мужские/женские после пожеланий владельца; не использовать случайно меняющийся голос. Эквализация, громкость и скорость одинаковые, чтобы не подменить сравнение качества настройками.

Тексты:

1. «На связи. Что нужно сделать?»
2. «Открываю браузер на ноутбуке. Готово.»
3. «Завтра, четвёртого октября, в девятнадцать часов нужно проверить проект.»
4. «Доход за выбранный период — двенадцать тысяч четыреста восемьдесят рублей. Это на восемь процентов больше прошлого периода.»
5. «Пришёл ответ на твоё письмо. Прочитать главное или открыть переписку?»
6. «Соединение прервалось. Файл уже сохранён, а сообщение ещё не отправлено.»
7. «Я нашёл два варианта. Первый проще в поддержке, второй быстрее на больших объёмах. Давай сравним их на твоей задаче.»

Нормализовать числа, даты, аббревиатуры и названия перед TTS. Словарь произношений хранится отдельно, одинаковые фразы можно кэшировать по голосу/версии/скорости. Длинные ответы делить по предложениям без разрыва слов; ограничить очередь и немедленно останавливать воспроизведение.

Замеры: время до первого звука, длительность генерации/аудио, peak RAM, CPU во время генерации и игры, стабильность 20 повторных фраз, корректная отмена и освобождение процесса. Прогретый и холодный запуск измерять отдельно. В покое ограниченная модель может оставаться в RAM по настройке, но не вести постоянный inference.

Итог: владелец слушает пронумерованные образцы без бренда, выбирает приятный и неутомительный голос; техническая таблица проверяет, подходит ли он ноутбуку и игре. Если бесплатные варианты проходят — постоянная цена TTS за использование 0 ₽, облачный путь не включаем по умолчанию. Если нет — обсуждаем конкретный недостаток, а не автоматически покупаем сервис.
